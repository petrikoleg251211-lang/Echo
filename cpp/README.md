# EchoLabyrinth_SFML — Нативна C++17 / SFML 2.6 гра для Windows 10/11 (v5.0 "Resonance" — Acoustic Roguelike)

Атмосферний 2.5D acoustic roguelike horror у процедурному підземному лабіринті з 32 кімнат на двовимірній сітці `(x, y)`, де кожен ваш крок, спрямований імпульс, частота сонара (`1 / 2 / 3`) та відбитий промінь стають і джерелом бачення, і гармонійною акустичною зброєю проти підземних мисливців.

---

## Що реалізовано в архітектурі v5.0 "Resonance" (Blocks 1–5)

### 1. Block 1 — Глобальна акустична симуляція та міжкімнатний звук
- **Глобальний лічильник шуму (`0..100`) і 4 рівні тривоги (`Quiet`, `Audible`, `Loud`, `Critical`):**
  Плавний спад тиші (`-8/с`, або `-12/с` із реліквією `Phase Dampener`), динамічний хвильовий осцилограф у HUD та система **Ghost Clear (`+50% Echo Shards`)** за зачищення кімнати без перевищення порогу `Audible` (`<= 25`).
- **Міжкімнатне поширення звуку через портали (`propagateNoiseAcrossPortals`):**
  Гучний шум (`>= 65`) проходить крізь відкриті або незаблоковані двері в сусідні кімнати з коефіцієнтом ослаблення `0.45`. При kritичному шумі (`>= 85`) сусідні мисливці здійснюють **Room Breach** (прорив у поточну кімнату; захищено прапорцем `breachTriggered` від нескінченного спавну).

### 2. Block 2 — Акустична фізика матеріалів (`8 SurfaceMaterial`)
- **8 матеріалів поверхонь:** `Stone`, `Metal`, `Water`, `Moss`, `ResonanceDoor`, `EchoCrystal` (підсилення променя `1.20x` + розщеплення луни), `VoidSponge` (поглинання `0.05x`), `Glass` (напівпрозоре заломлення + руйнування `shatterWallSegmentsNear` при потужному імпульсі з викидом шуму `+40`).
- **Водне загасання (`Water`):** зменшує швидкість руху (`0.72x`) і підвищує шум кроків (`1.45x`).

### 3. Block 3 — Тактичний арсенал (`Sonar Frequency 1/2/3`, `Echo Trap`, `Charged Ping`)
- **3 частотні режими сонара (`Клавіші 1 / 2 / 3`):**
  - `[1] Low (Sub-Bass)` — пробиває тонкі стіни, підвищений шум (`1.35x`).
  - `[2] Standard (Balanced)` — збалансована дальність, 4 відбиття та стандартна шкода.
  - `[3] High (Ultrasonic)` — тихий імпульс (`0.55x` шуму), `+1` відбиття, розкриває замаскованих `Mimic` і завдає `+35%` шкоди `BlindAngler`, `Mimic` та у фінальній фазі боса.
- **Заряджений сонар (`Charged Ping` — утримання `LMB / E`):** шкала заряду до `2.25x` шкоди, розбиває скляні перегородки (`Glass`) та відкриває приховані кімнати `Secret [?]`.
- **Акустичні пастки (`Echo Trap [Q]`):** автономний маяк, що періодично випускає локальні імпульси приманки та вибухає резонансною хвилею при наближенні ворога.

### 4. Block 4 — Розширений бестіарій (`8 EnemyVariant`)
- `Stalker` — швидкий акустичний мисливець.
- `Warden` — броньований вартовий із фронтальним щитом; вразливий у спину та до відбитих променів.
- `Shrieker` — стаціонарна кристалічна турель, що випускає дисонансні кільця у відповідь на шум.
- `Phantom` — фазовий мисливець, вразливий після підсвічування відбитими лунами.
- `Mimic` — маскується під скриню або колону (`disguised`); викривається високочастотним сонаром `[3]` або відбитою луною.
- `BlindAngler` — повільний безокий хижак із фальшивим приманним маяком; шаленіє (`2.35x` швидкості) при критичному шумі.
- `EchoSwarm` — рій мікрорезонаторів, що повторює та підсилює звукові імпульси гравця (`+12` до глобального шуму).
- `AbyssalBoss (The Choir Sovereign)` — 3-фазний бос із динамічною акустикою арени:
  - **Phase I — Harmonic Choir (`> 66% HP`):** класичне полювання та гармонійне відбиття.
  - **Phase II — Dissonant Pulse (`66%..33% HP`):** періодичні дисонансні ударні хвилі кожні `4.8 с`, що підвищують шум арени та перевіряють позиціонування.
  - **Phase III — Abyssal Silence (`<= 33% HP`):** поглинання прямих низькочастотних ударів (`0.35x`), тоді як відбиті від стін луни та `High-Freq [3]` промені завдають `1.85x` резонансної шкоди.

### 5. Block 5 — Динамічні події кімнат, 12 Реліквій, 12 Audio-Lore Codex та Save V5
- **Динамічні акустичні події (`RoomEvent`):**
  - `Echo Storm` — періодичні атмосферні розряди, що безкоштовно освітлюють залу, але додають фоновий шум (`+6`).
  - `Acoustic Blackout` — густий туман поглинає `32%` дальності сонара, проте винагороджує `+50% Echo Shards` за зачищення.
  - `Resonance Overcharge` — кристалічна гармоніка подвоює тривалість життя луни (`2.0x`), прискорює заряд резонаторів і дає `+25%` шкоди сонаром.
- **12 акустичних реліквій (`RelicId`):** 8 класичних реліквій + `Phase Dampener` (`+50%` швидкості спаду шуму, `-20%` генерації шуму), `Ultrasonic Lens` (`+2 Echo Traps`, `+45%` шкоди на частоті `[3]`), `Abyssal Tuning Fork` (трофей боса: `+35%` шкоди сонаром і `+25% Echo Shards`).
- **Кодекс аудіо-лору (`Audio-Lore Codex [J]`):** 12 унікальних записів експедиції, які зберігаються між забігами у форматі збережень **Save V5 (`ELSV5`)** із повною зворотною сумісністю з V4 та V3.

| Клавіша / Дія | Призначення |
| :--- | :--- |
| **W / A / S / D** або **Стрілки** | Рух дослідника та перехід крізь двері `N / E / S / W` |

| **Space (Пробіл)** | Потужний круговий імпульс (`Radial Pulse` 360°) |

| **Q** | Встановити автономну акустичну пастку (`Echo Trap`) |
| **F** | Взяти реліквію / прочитати `Codex Log` / купити в `Shop` / активувати `Sanctuary` |

| **Tab або M** | Відкрити/закрити повну 2D-карту лабіринту та список зібраних реліквій |

| **F11** | Перемикання повноекранного режиму (`Fullscreen` / `Windowed` із Letterbox 16:10) |
| **Escape (ESC)** | Пауза / Налаштування / Повернення назад |

## Швидка збірка на Windows 10 / 11 та Linux

### Варіант А — Через `build_windows.bat` (Автоматичний на Windows)
Просто двічі клікніть **`build_windows.bat`** у папці `cpp/` або запустіть його з термінала. Скрипт автоматично збере `Release`-версію, скопіює `assets/models/*.obj` та запустить усі 17 наборів `--self-test`.

### Варіант Б — Командний рядок CMake (Visual Studio 2022 / GCC)
```powershell
cd cpp
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
.\build\Release\EchoLabyrinth_SFML.exe --self-test
.\build\Release\EchoLabyrinth_SFML.exe
```
