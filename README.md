# EchoLabyrinth — v5.1.0 "Resonance" (C++17 / SFML 2.6.1 & Web Studio)

A standalone, zero-placeholder **C++17 / SFML 2.6.1** acoustic roguelike survival horror game (`cpp/`) paired with an interactive Web Audio & Acoustic Studio (`src/`).

- **Native C++17 Engine (`cpp/`)**: 23 modular C++17 translation units (each `<= ~900` lines), OpenAL 3D spatial audio, **5-track procedural dark-ambient OST (`SoundtrackComposer.cpp`)**, Hit-Stop & Attack Telegraphing, 4 Difficulty Modes (`Explorer`, `Surveyor`, `Abyssal`, `Silence`), 3-Room Interactive Tutorial, Fear Readability HUD, 8 acoustic materials, 8 enemy archetypes + 3-phase Final Boss (*The Choir Sovereign*), 32-room procedural labyrinth, 12 Relics, 12 Audio-Lore Codex entries, ELSV6 checksummed saves (with V1–V5 migration), `--balance-report` (1,000 headless bot runs), and a **deterministic 18-suite headless `--self-test`**.
- **Full C++ Documentation & Build Instructions**: See [`cpp/README.md`](cpp/README.md) and [`CHANGELOG.md`](CHANGELOG.md).
