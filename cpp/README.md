# EchoLabyrinth_SFML — Нативна C++17 / SFML 2.6 гра для Windows 10/11 (v3.0 — 2.5D/3D Assets & Spatial Audio)

Атмосферний 2.5D stealth-horror у темному підземному лабіринті з 15 кімнат, де гравець орієнтується за допомогою поширення, заломлення та відбиття звукових хвиль.

---

## 1. Архітектура 2.5D/3D Графіки, Асетів та Просторового Звуку

- **Централізований менеджер ресурсів (`echo::AssetManager`)**:
  - Завантажує та кешує 7 тривимірних моделей у форматі **Wavefront OBJ (`cpp/assets/models/*.obj`)**: дослідник (`surveyor_rig.obj`), сліпий мисливець (`listener_stalker.obj`), броньований вартовий (`listener_warden.obj`), кристал-резонатор (`resonator_crystal.obj`), гармонічний важіль (`harmonic_lever.obj`), термінал геодезиста (`surveyor_terminal.obj`) та вентиляційна турбіна (`vent_turbine.obj`).
  - Виконує **2.5D косокутну проєкцію (`renderMesh25D`)** із сортуванням граней за глибиною (`Z`) та динамічним нормалізованим освітленням (`N · L`) від активних акустичних хвиль.
  - Генерує та кешує **6 процедурних RGBA-текстур матеріалів (`64x64 px`)** із мікротріщинами, швами кладки, заклепками, іржею та брижами води (`Stone`, `Concrete`, `Metal`, `Water`, `DampMoss`, `ResonanceDoor`).
  - Має автоматичний процедурний fallback: якщо бінарний файл запущено без папки `assets/`, усі моделі та текстури відновлюються в пам'яті без падінь.
- **Просторове 3D-аудіо OpenAL та 4-шаровий адаптивний саундтрек (`echo::AudioManager`)**:
  - 20-голосний поліфонічний пул `sf::Sound` із просторовою локалізацією **OpenAL 3D (`sf::Listener` + `sf::Sound::setPosition`)** та реальним розрахунком приглушення крізь стіни (`AcousticSystem::computeTransmissionFactor`).
  - Окремі звуки кроків для кожного матеріалу (`Stone`, `Concrete`, `Metal`, `Water`, `DampMoss`), дихання при виснаженні, серцебиття при небезпеці, тріск крихкого сланцю (`ShaleCrack`), гармонічний резонанс кристалів (`ResonatorHum`) та 3D-звуки ворогів (`Stalker` і `Warden`).
  - **4 безшовні музичні шари** (`Exploration`, `Tension`, `Pursuit`, `Sanctum`) із плавним кросфейдом та 4-канальним мікшером гучності у меню `Settings` (`Master`, `Music`, `SFX`, `Ambient`).

Повний перелік ресурсів та ліцензій (**CC0 1.0 Public Domain**) наведено у файлі `cpp/assets/ASSET_MANIFEST.md`.

## 2. Вимоги для збірки на Windows 10/11 (x64)

- **Visual Studio 2022** (Community / Professional / Enterprise) з обраним пакетом **"Desktop development with C++"** (містить компілятор MSVC та CMake).
- **CMake 3.20+** та **Git** (для автоматичного завантаження SFML 2.6.1 через `FetchContent`, якщо SFML не встановлено локально).

---

## 3. Збірка та запуск у 1 клік (`build_windows.bat`)

1. Відкрийте папку `cpp/`.
2. Запустіть **`build_windows.bat`** подвійним кліком.
3. Скрипт автоматично:
   - Сконфігурує CMake у папці `cpp/build/`,
   - Завантажить і збере SFML 2.6.1 (під час першого запуску це триває ~1–2 хвилини),
   - Скомпілює `EchoLabyrinth_SFML.exe` у режимі `Release`,
   - Скопіює каталог `assets/` (3D `.obj` моделі та маніфест) і всі `.dll` (`openal32.dll`, `sfml-*.dll`) поруч із `.exe`,
   - Прожене 9-рівневий автоматичний самотест (`--self-test`) і відкриє вікно гри.

---

## 4. Ручна збірка через термінал PowerShell або CMD

Відкрийте **PowerShell** або **x64 Native Tools Command Prompt for VS 2022** у папці `cpp/`:

```powershell
# 1. Генерація проєкту Visual Studio 2022 (x64)
cmake -B build -G "Visual Studio 17 2022" -A x64

# 2. Компіляція конфігурації Release (або Debug)
cmake --build build --config Release

# 3. Перевірка 9 вбудованих тестів (включно з 3D-моделями та BFS-прохідністю 15 кімнат)
.\build\Release\EchoLabyrinth_SFML.exe --self-test

# 4. Запуск гри
.\build\Release\EchoLabyrinth_SFML.exe
```

## 5. Керування в грі

- **WASD / Стрілки** — Пересування дослідника.
- **LShift (утримувати)** — Тихий крок (`Sneak`): мінімальний радіус звуку кроків, безпечний прохід по крихкому сланцю (`Brittle Shale`).
- **LCtrl або C (утримувати)** — Біг (`Sprint`): швидкий рух, але витрачає витривалість і створює потужні звукові хвилі.
- **Ліва кнопка миші (LMB) або E** — Спрямований сонарний імпульс (конус 60° у напрямку курсора; заряджає кристали-резонатори).
- **Пробіл (Space)** — Круговий резонансний імпульс на 360°.
- **Права кнопка миші (RMB) або G** — Кинути камінь-приманку (`Decoy Stone`), щоб відволікти сліпого мисливця (`The Listener`).
- **F** — Взаємодія: перемкнути гармонічний важіль дверей або прочитати журнал геодезиста (`+1 Decoy Stone`).
- **Tab або M** — Відкрити/закрити тактичну карту всіх 15 камер лабіринту.
- **F5 / F9** — Швидке збереження / завантаження контрольної точки (`echolabyrinth_save.dat`).
- **F11** — Повноекранний / віконний режим.
- **Esc або P** — Меню паузи.
