# EchoLabyrinth_SFML — Нативна C++17 / SFML 2.6 гра для Windows 10/11

Атмосферний 2D stealth-horror у темному підземному лабіринті з 15 кімнат, де гравець орієнтується за допомогою поширення та відбиття звукових хвиль.

---

## 1. Вимоги для збірки на Windows 10/11 (x64)

- **Visual Studio 2022** (Community / Professional / Enterprise) з обраним пакетом **"Desktop development with C++"** (містить компілятор MSVC та CMake).
- **CMake 3.20+** та **Git** (для автоматичного завантаження SFML 2.6.1 через `FetchContent`, якщо SFML не встановлено локально).
- Жодних браузерів, Node.js, серверів або зовнішніх асетів не потрібно: гра генерує всі аудіо-буфери OpenAL (`sf::SoundBuffer`) процедурно в пам'яті та має як підтримку системних шрифтів Windows (`Consolas`, `Segoe UI`), так і вбудований векторний рендерер символів.

---

## 2. Збірка та запуск у 1 клік (`build_windows.bat`)

1. Відкрийте папку `cpp/`.
2. Запустіть **`build_windows.bat`** подвійним кліком.
3. Скрипт автоматично:
   - Сконфігурує CMake у папці `cpp/build/`,
   - Завантажить і збере SFML 2.6.1 (під час першого запуску це триває ~1–2 хвилини),
   - Скомпілює `EchoLabyrinth_SFML.exe` у режимі `Release`,
   - Скопіює всі потрібні `.dll` (`openal32.dll`, `sfml-graphics-2.dll` тощо) поруч із `.exe`,
   - Прожене автоматичний самотест (`--self-test`) і відкриє вікно гри.

---

## 3. Ручна збірка через термінал PowerShell або CMD

Відкрийте **PowerShell** або **x64 Native Tools Command Prompt for VS 2022** у папці `cpp/`:

```powershell
# 1. Генерація проєкту Visual Studio 2022 (x64)
cmake -B build -G "Visual Studio 17 2022" -A x64

# 2. Компіляція конфігурації Release (або Debug)
cmake --build build --config Release

# 3. Перевірка вбудованих тестів (необов'язково)
.\build\Release\EchoLabyrinth_SFML.exe --self-test

# 4. Запуск гри
.\build\Release\EchoLabyrinth_SFML.exe
```

Також проєкт можна відкрити напряму у **Visual Studio 2022** через **File -> Open -> CMake...** і вибрати файл `cpp/CMakeLists.txt`.

## 4. Керування в грі

- **WASD / Стрілки** — Пересування дослідника.
- **LShift (утримувати)** — Тихий крок (`Sneak`): мінімальний радіус звуку кроків, вороги не чують вас на відстані.
- **LCtrl або C (утримувати)** — Біг (`Sprint`): швидкий рух, але витрачає витривалість і створює потужні звукові хвилі.
- **Ліва кнопка миші (LMB) або E** — Спрямований сонарний імпульс (конус 60° у напрямку курсора).
- **Пробіл (Space)** — Круговий резонансний імпульс на 360°.
- **Права кнопка миші (RMB) або G** — Кинути камінь-приманку (`Decoy Stone`), щоб відволікти сліпого мисливця (`The Listener`).
- **F** — Взаємодія: перемкнути гармонічний важіль дверей або прочитати журнал геодезиста (`+1 Decoy Stone`).
- **Tab або M** — Відкрити/закрити тактичну карту всіх 15 камер лабіринту.
- **F5 / F9** — Швидке збереження / завантаження контрольної точки (`echolabyrinth_save.dat`).
- **F11** — Повноекранний / віконний режим.
- **Esc або P** — Меню паузи.
